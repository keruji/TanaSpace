Features

A practical space for the things you own, use, and plan.

TanaSpace is designed around everyday records: items, reminders, groceries, recipes, computer builds, and other personal systems that are easier to manage when they live in one organized place.

Item Records

Record devices, consumables, tools, supplies, or almost anything with details like item type, variant, size, weight, brand, notes, and photos later.

Expiration and Warranty Reminders

Add expiration dates, warranty periods, renewal dates, or service schedules so TanaSpace can remind you before something is wasted, forgotten, or out of coverage.

Grocery Checklists

Start from reusable grocery templates, then remove or add items for a specific scheduled grocery run without changing the original template.

Recipe Collections

Save recipes with ingredients, step-by-step instructions, estimated time, preparation notes, and the actions needed at each stage.

PC Build Planner

Record a current computer build, track components, and plan future builds with parts lists, upgrade ideas, and checklist progress.

More Tools Later

The feature set can keep growing as the product becomes clearer, with new spaces for other routines, collections, and planning workflows.

About

A personal space, built one step at a time.

TanaSpace now has a Django foundation with personal accounts and a dashboard. Inventory, reminders, and planning tools are next as your space grows.

Roadmap

From preview to a complete personal space platform.

The roadmap is organized around major product milestones: first shaping the landing page, then proving the frontend experience, adding the Django backend, preparing the release, and finally bringing the experience to mobile.

Phase 01

Landing Page

Define the product message, feature direction, roadmap, and first public-facing page for TanaSpace.

Phase 02 · Current

Frontend Preview

Build the first preview interface and validate the core layouts, item flows, and product experience.

Phase 03

Backend Foundation

Start the Python and Django backend with models, database structure, authentication, and API endpoints.

Phase 04

Feature Expansion

Add the main app features, connect frontend workflows, and finalize backend behavior.

Phase 05

Release

Polish the product, test core paths, prepare deployment, and launch the first stable version.

Phase 06

Initial Mobile App

Design and build the first mobile experience after the web app and backend are stable.
